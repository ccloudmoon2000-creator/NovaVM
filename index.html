Escolhe uma imagem, ajusta a memória e prepara uma sessão de emulação. A execução é feita no teu dispositivo; o site não envia o ficheiro ISO para um servidor.

01 / Imagem do sistema

Seleciona uma ISO ou um disco IMG compatível com o motor x86.

Nenhum ficheiro selecionado.
Compatibilidade não garantidaO motor v86 emula um PC x86 antigo. Muitas ISOs modernas, sistemas ARM e versões atuais do Android podem não arrancar. O ficheiro é aberto localmente pelo navegador.
Para maior compatibilidade, começa com um sistema x86 leve conhecido por funcionar no v86. Imagens muito grandes podem exceder a memória disponível.

Limitações de hardware

As opções de configuração não equivalem a um PC físico completo.

  • RAM: define a memória do convidado dentro do que o navegador consegue reservar; valores altos podem falhar.
  • Disco: nesta versão, o valor é informativo. Não cria um disco virtual persistente nem guarda alterações entre sessões.
  • CPU: o motor emula uma CPU x86; não permite escolher livremente modelo, número de núcleos ou frequência.
  • GPU: é vídeo VGA emulado, não uma GPU física com passthrough nem aceleração 3D completa.
  • Android: Android moderno pode exigir instruções de CPU, aceleração gráfica ou arquitetura ARM que este motor não fornece. A opção Android x86 é apenas um perfil experimental.
  • GitHub Pages: hospeda ficheiros estáticos; não fornece servidor de virtualização. Todo o trabalho corre no dispositivo do visitante.
